# Changelog

## 1.0.1 - 2026-09-05

- License the Windows implementation under MIT and retain upstream attribution.
- Include project and .NET runtime license notices in published builds and local installations.
- Document independent project status and distribution requirements.
- Add complete release ZIP packaging and installation without a build or SDK.

## 1.0.0 - 2026-09-04

- Add Oh My Zsh-style warp points for Windows PowerShell and Command Prompt.
- Support adding, overwriting, removing, listing, showing, cleaning, opening, and navigating points.
- Store points in the compatible `%USERPROFILE%\.warprc` text format.
- Add a one-command installer that configures the user PATH and both PowerShell profile locations.
